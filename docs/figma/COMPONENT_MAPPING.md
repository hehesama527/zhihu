## 变量映射

### 颜色变量

- `theme/zhihu/accent` → `#c55a11`
- `theme/zhihu/accent-soft` → `#f0c7a4`
- `theme/twitter/accent` → `#0f6c5a`
- `theme/twitter/accent-soft` → `#bfe8da`
- `theme/images/accent` → `#0b7a75`
- `theme/images/accent-soft` → `#bfe9e4`

### 间距变量

- `space/xs` → `0.5rem`
- `space/sm` → `0.75rem`
- `space/md` → `1rem`
- `space/lg` → `1.5rem`
- `space/xl` → `2rem`
- `space/2xl` → `3rem`

### 圆角变量

- `radius/sm` → `10px`
- `radius/md` → `16px`
- `radius/lg` → `18px`
- `radius/xl` → `20px`
- `radius/2xl` → `28px`
- `radius/full` → `999px`

### 阴影变量

- `shadow/sm` → `0 1px 3px rgba(0, 0, 0, 0.05)`
- `shadow/md` → `0 2px 8px rgba(197, 90, 17, 0.3)`
- `shadow/lg` → `0 4px 20px rgba(197, 90, 17, 0.08)`
- `shadow/xl` → `0 8px 30px rgba(197, 90, 17, 0.15)`
- `shadow/2xl` → `0 12px 50px rgba(197, 90, 17, 0.2)`

## 使用指南

1. 在 Figma 中安装 Code Connect 插件
2. 导入此项目的配置文件
3. 组件会自动映射到对应的 React 组件
4. 变量会同步到 CSS 自定义属性

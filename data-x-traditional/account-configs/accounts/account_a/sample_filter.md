# 筛选文档

## 使用原则

- 这份文档只决定哪些源样本可以进入风格学习，不决定目标账号最终写什么。
- 重点是保留可迁移的说话方式、判断节奏和表达结构，不是提前把样本改写成目标账号成品。
- 默认轻质检，只排除明显会污染风格学习的样本。

## 优先保留

- 判断先行
- 因果解释
- 条件表达
- 转折表达
- 对比关系
- 递进关系
- 市场结构
- 节奏分析
- 资金观察
- 叙事质量
- 观察结论
- 短段落推进

## 优先排除

- 生活流
- 家庭日常
- 纯鸡汤
- 纯情绪抒发
- 空泛金句
- 交易流水账
- 晒收益
- 喊单
- 品牌 slogan
- 高重复度语句
- 跟单煽动
- 非交易话题

## 硬排除短语

- 猛猛的干
- 我买了点
- 求来一波
- 稳赚
- 抄底！！！

## 规则开关

- requireKnowledgeStructure: false
- rejectAssetCentricHotTakes: false
- preferCalmKnowledgeTone: true
- rejectLifestyleContent: true
- rejectTradeDiaryTone: true
- rejectBrandSlogans: true
- rejectHighlyRepetitiveLines: true
